動腦時間：太空失重如何測量質量？

💡 課本動腦提問 · 慣性質量 vs 重力質量

在太空中失重狀態下，無法使用天平，如何測量質量？

天平是依賴地球重力（萬有引力）達到力矩平衡。在太空失重環境下，重力效應消失，天平與彈簧秤皆無法直接稱重！但依據牛頓第二定律 \(F = m imes a\)，物體的「慣性」依然存在，施加已知定力 \(F\) 並測量加速度 \(a\)，即可求出質量 \(m = rac{F}{a}\)！

🧑‍🚀
太空失重狀態
g = 0 （無下壓力）
m = F / a （慣性質量）

牛頓第二定律太空測量任務

依據太空站推進器數據，計算太空人與貨物質量

1 核心原理思考：質量等於慣性大小

物體在太空中雖然「失重（重量為零）」，但物體所含物質的「質量（慣性）」並沒有改變。要改變物體的運動狀態，依然需要施力！

🧑‍🚀 任務一：太空人質量測量（SLAMMD 模擬） F = 160 N

已知太空站儀器對一位連同太空衣的太空人施加恆定推力 F = 160 N，測得其瞬間加速度為 a = 2.0 m/s²，則該太空人的總質量為：

\(m = rac{F}{a} = rac{160}{2.0} =\) 公斤（kg）
📦 任務二：太空補給物資箱質量測量 F = 300 N

對未知物資箱施加推力 F = 300 N，測得加速度為 a = 2.5 m/s²，則該物資箱的質量為：

\(m = rac{F}{a} = rac{300}{2.5} =\) 公斤（kg）
🚀
答對了！成功掌握慣性質量測量法！
利用已知推力與加速度比值 \(m = F/a\)，在任何無重力環境都能測出質量。

真實太空站如何為太空人量體重？

🎯 NASA SLAMMD 線性加速度質譜儀

國際太空站（ISS）安裝的體重計就是依據牛頓第二定律！太空人固定在導軌上，由彈簧釋放精確恆力 \(F\)，光學編碼器測量加速度 \(a\)，直接算出體重 \(m=F/a\)。

🔄 BMMD 彈簧震盪週期體重計

另一種方式是太空人坐上彈簧震盪椅，測量來回震盪的週期 \(T\)。質量越大週期越長（\(T = 2\pi\sqrt{m/k}\)），亦可由震盪頻率反推質量。

太空與慣性質量隨堂通關評量（4 題）

得分：0 / 4
Q1. 在太空站失重環境中，下列哪一種測量工具「完全無法正常使用」？
解析：天平需要兩側物體受重力產生力矩才能平衡，失重狀態下重力為零，天平無法傾斜平衡。
Q2. 在太空中對一質量 \(60 ext{ kg}\) 的太空人施加 \(120 ext{ N}\) 的推力，太空人的加速度為多少？
解析：由牛頓第二定律 \(a = rac{F}{m} = rac{120}{60} = 2.0 ext{ m/s}^2\)。
Q3. 將同一個物體分別置於「地球」、「月球」與「太空站」，其質量大小關係為何？
解析：質量是物體所含物質的本質（慣性大小），不隨地點或重力環境改變，三者完全相等！
Q4. 利用 \(m = F/a\) 在太空測量質量時，若施加的推力 \(F\) 加倍，則測得的加速度 \(a\) 與計算的質量 \(m\) 會如何？
解析：推力 \(F\) 加倍時，產生的加速度 \(a\) 亦成正比加倍，兩者比值 \(m = F/a\) 恆定不變。
