💡 破題黃金心法（幾何微分）：
「x-t 圖的直線斜率，就是 v-t 圖上的 y 軸速度數值」！
🔍 三階段斜率對應拆解：
  • 🟢 第 1 階段（0～2 秒，向上傾斜線）： $$ \text{斜率 } = \frac{\Delta x}{\Delta t} = \frac{4 - 0}{2 - 0} = \mathbf{+2\text{ m/s}} $$ 對應 v-t 圖為橫軸上方的正值水平階梯（+2）。
  • 🟡 第 2 階段（2～4 秒，水平直線）： 位置維持在 4m 不動，\( \Delta x = 0 \Rightarrow \mathbf{v = 0\text{ m/s}} \)，對應 v-t 圖為落在時間軸上的零階梯。
  • 🔴 第 3 階段（4～6 秒，向下傾斜線）： $$ \text{斜率 } = \frac{0 - 4}{6 - 4} = \mathbf{-2\text{ m/s}} $$ 對應 v-t 圖為橫軸下方的負值水平階梯（-2）。
  • 🏆 結論：v-t 圖必定由「正值階梯 ➔ 零階梯 ➔ 負值階梯」構成，故選 (B)！
