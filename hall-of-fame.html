  • ✓ 起爆原理、矽藻土固態化與 350+ 項專利
  • ✓ 史實闢謠 (無數學獎真相) 與搞笑諾貝爾獎

  • ✓ 1905 奇蹟年四大重大突破論文
  • ✓ 光電效應榮獲 1921 年諾貝爾物理學獎

  • ✓ 哈伯定律：星系退行速度與距離成正比
  • ✓ 宇宙膨脹第一直接觀測證據

  • ✓ 小獵犬號五年環球考察日記
  • ✓ 物種起源：過度繁殖、生存競爭與適者生存
  • ✓ 徹底改變現代生物學與人類自然觀

  • ✓ 古冰川沉積物分布地質證據

  • ✓ 候風地動儀：八龍吐珠與都柱慣性原理
  • ✓ 水運渾天儀與日月運行天球儀器
  • ✓ 世界上最早精確計算圓周率的科學巨匠

羅伯特·虎克

Robert Hooke (1635–1703)

  • ✓ 虎克定律：彈簧伸長量與受力成正比 $F=k\Delta x$
  • ✓ 英國皇家學會實驗主管與萬能發明家

  • ✓ 「給我一個支點，我就能舉起整個地球」
  • ✓ 螺旋抽水機與敘拉古保衛戰防禦機械
