會考核心考點與公式總結

📌 自由落體等加速度特性

在地球表面附近，忽略空氣阻力時，任何自由落下之物體，其加速度大小恆為：

\(a = g pprox 9.8 ext{ m/s}^2\)（方向鉛直向下）
⚖️ 地球重力（萬有引力）大小

依據 \(F = m imes a\)，質量 \(m\) 之物體在地球表面所受的重力大小為：

\(F_{ ext{重力}} = m imes g = 50 imes 9.8 = 490 ext{ N}\)
🪶 質量無關性（伽利略斜塔實驗）

不論物體是 \(50 ext{ kg}\) 或 \(1 ext{ kg}\)，若同時同高度釋放，落下的加速度相同，著地時間亦完全相同！

🔄 公斤重與牛頓的單位換算

\(1 ext{ kgw}\) 即質量 \(1 ext{ kg}\) 所受地球引力： \(1 ext{ kgw} = 1 ext{ kg} imes 9.8 ext{ m/s}^2 = 9.8 ext{ N}\) 故 \(50 ext{ kg}\) 物體重 \(50 ext{ kgw} = 490 ext{ N}\)。

即時概念闖關評量（4 題）

得分：0 / 4
Q1. 質量 \(50 ext{ kg}\) 的物體在地球上自由落下，第 3 秒末的瞬間速度大小為多少？
解析：\(v_3 = v_0 + gt = 0 + 9.8 imes 3 = 29.4 ext{ m/s}\)。
Q2. 若將落下物體改為質量 \(100 ext{ kg}\)（增加為2倍），忽略空氣阻力，其下落加速度為多少？
解析：自由落體之加速度與物體質量無關，地球表面附近恆為 \(g = 9.8 ext{ m/s}^2\)。
Q3. 質量 \(50 ext{ kg}\) 的物體在落下過程中，每秒所受的地球引力大小為何？
解析：\(F = mg = 50 imes 9.8 = 490 ext{ N}\)，在落下過程中重力恆定不變。
Q4. 自由落體運動是屬於下列哪一種運動？
解析：自由落體方向固定鉛直向下，加速度大小固定為 \(g=9.8 ext{ m/s}^2\)，故為等加速度直線運動。
